# Cricket Fantasy

A social, season-long fantasy cricket platform inspired by the private-league experience of traditional fantasy sports.

**Status:** foundation in progress. MLC is the first target tournament; IPL and other leagues are planned. This repository is not a live fantasy service yet.

The first release will focus on free private leagues, exclusive player drafts, head-to-head fantasy rounds, standings, and transparent cricket scoring.

See `docs/` for the product and technical plans as they land.
